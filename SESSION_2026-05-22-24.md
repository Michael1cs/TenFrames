### Welcome narration: once per language, not every time
The kid kept hearing "Welcome to Ten Frames…" every single time they
navigated back to Home (from FreePlay, Adventure, anywhere). Two
sessions ago I moved the narration timers to `useFocusEffect` so they
cancelled on blur — but that meant the sequence ALSO re-fired on every
re-focus.

Fix in `src/components/onboarding/ModeChoice.tsx`:

- Module-level `let narrationPlayedForLang: string | null = null`.
- `useFocusEffect` first checks if `narrationPlayedForLang === currentLang`
  and bails. Otherwise sets the guard and schedules the welcome + mode
  question + mode cards.
- `currentLang = i18n.language` is in the `useCallback` deps array.
  Switching the language flag resets the guard and the narration plays
  again in the new language, which is the parent's expectation.

After this: the narration plays once on cold start (when Home first
gets focus) and once after each language switch. Return trips from
FreePlay / Adventure stay silent.

## Pre-archive checklist (manual, in Xcode)

1. **Signing & Capabilities** → Team selected for the TenFrames target.
2. **App Store Connect** → IAP `com.tenframes.premium_unlock` is in
   "Ready to Submit".
3. **Screenshots** prepared per device size (iPhone 6.7", iPhone 6.9",
   iPad 12.9" if iPad supported).
4. **App Preview videos** (optional, up to 3 per device size):
   15-30 s, captured at the device's native resolution. Easiest path:
   QuickTime Player → File → New Movie Recording → camera = iPhone,
   record session, save .mov, upload directly to App Store Connect.
5. **Privacy policy URL** hosted somewhere; kids-compliant (we collect
   nothing, no analytics SDKs).

## Archive flow

In Xcode:
1. Scheme = TenFrames, Configuration = Release
2. Destination = "Any iOS Device (arm64)"
3. Product → Archive (will run npm bundle internally)
4. After archive: Distribute App → App Store Connect → Upload
